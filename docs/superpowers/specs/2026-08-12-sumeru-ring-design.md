# SUMERU RING 首期设计规格

## 产品定位

纯前端个人工作台。首期内容全部为工具，未来可以增加网址、文档或代码片段。所有计算在浏览器本地完成。

## 视觉设计

- 新极简主义：清晰排版、足够留白、低密度边框，不使用沉重阴影。
- 主色为舞台蓝，辅助色为暖光橙，淡绿色作为工作区背景。
- 背景使用低对比度、大小不一的圆环构成平面纹理。
- 左侧导航可展开或收缩为图标栏，状态本地保存。
- 桌面端工具输入与结果保持左右布局，移动端改为上下布局。

## 首期工具

### JWT 解析

解析 Header、Payload 和签名，友好显示时间字段。支持用密钥验证 HS256、HS384、HS512。明确提示解析成功不代表签名可信，密钥不保存。

### 二维码生成与识别

生成支持文本、网址、Wi-Fi、联系人、邮件，支持尺寸、纠错等级、颜色、中心 Logo、点阵和定位点样式；导出 PNG/SVG。识别支持拖拽、粘贴截图和文件选择，不调用摄像头。

### JSON 工具

支持转义、去除转义、格式化、压缩、树形/代码展示、搜索和文件导入导出。目标规模 1-10 MB，处理放入 Web Worker，错误显示行列和上下文。

### URL 编解码

支持完整 URL 与组件模式，对应 encodeURI/decodeURI 和 encodeURIComponent/decodeURIComponent。支持交换输入输出、复制，并解释两种模式差异。

### 字符统计

分类展示汉字、中文符号、字母、英文符号、数字、空格、换行、制表符和其他字符。原始字符数与加权总数分开显示。加权公式为：汉字×2 + 中文符号×2 + 字母 + 英文符号 + 数字 + 空格 + 其他字符；换行和制表符属于单独展示的其他字符，每个按 1 计。

## 通用说明结构

每个工具包含：用途、输入格式、操作步骤、处理规则、示例、常见错误、安全或隐私注意事项。

## 验收标准

- 五个工具在桌面端与移动端可完成核心流程。
- 侧栏可展开/收缩，页面路由刷新可用。
- 敏感输入不持久化、不上传。
- 关键纯函数测试通过，类型检查与生产构建通过。
- README 包含本地运行和 Nginx 部署步骤。
