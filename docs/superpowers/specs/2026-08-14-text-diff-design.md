# 文本比较工具设计

## 目标

新增“小工具 > 文本比较”，用于比较两段文本的行级和行内差异。结果采用 Git 提交对比风格，支持同步滚动、差异统计和逐项跳转，长文本计算不能阻塞页面。

## 页面与路由

- 工具名称：文本比较
- 分类：文本处理
- 路由：`/tools/text-diff`
- 注册表关键词：文本、比较、差异、diff、git
- 页面沿用 `ToolPageHeader`、`.sr-panel` 和 `ToolDocumentation`。

## 输入与操作

页面顶部并排放置“原始文本”和“修改后文本”两个固定高度的多行输入框，移动端改为上下排列。

操作区包含：

- “开始比较”主按钮；
- “清空”按钮；
- “忽略空白”开关，默认关闭。开启后，行首缩进、连续空格和行尾空格差异不计入比较结果。

只有点击“开始比较”才计算结果。清空同时重置文本、结果、统计、跳转位置和滚动位置。

## 差异计算

使用成熟的 `diff` 库，不自行实现 LCS 算法。

计算分为两层：

1. 按行对比，识别未变化、新增、删除和修改行；
2. 对成对的删除行和新增行进行词级对比，必要时细化到字符级，使单行内部变化可见。

差异计算放入 Web Worker。页面向 Worker 发送两段文本及忽略空白选项，Worker 返回适合渲染的普通结构化数据，不返回 HTML。

## 结果展示

结果使用左右并排的 Git 风格视图：

- 左侧为原始文本，删除行为浅红背景，删除片段使用更深红色；
- 右侧为修改后文本，新增行为浅绿背景，新增片段使用更深绿色；
- 未变化行使用普通背景；
- 缺失侧显示空占位行，确保两边差异块垂直对齐；
- 两侧分别显示对应文本的真实行号。

结果面板具有固定高度，左右两侧的垂直和水平滚动同步。同步逻辑带重入保护，避免两个滚动事件互相触发抖动。

## 统计与导航

结果顶部展示：

- 新增行数；
- 删除行数；
- 修改块数；
- 差异总数。

每个连续差异块视为一个可导航差异。提供“上一个差异”“下一个差异”和当前位置，如 `3 / 12`。跳转时两侧结果面板同步滚动到目标差异块，并短暂突出当前块；不得调用页面级 `scrollIntoView` 导致页面位置变化。

无差异时展示明确的“文本内容一致”状态。输入为空仍允许比较；两个空文本视为一致。

## 仅看差异

结果区提供“只看差异”开关，默认关闭。开启后以完整比较结果为数据源，仅渲染每个差异块前后各 3 行未变化上下文；相邻差异的上下文范围重叠时自动合并。

连续隐藏区域合并为一条“已隐藏 N 行”占位条。点击占位条只展开该隐藏区域，不关闭“只看差异”模式。重新比较或清空时重置手动展开状态。差异统计、真实行号以及上一个和下一个差异导航始终基于完整结果，不受精简展示影响。

## 模块边界

- `src/features/text-diff/lib/textDiff.ts`：差异数据类型、差异计算和统计转换；
- `src/features/text-diff/text-diff.worker.ts`：Worker 消息入口；
- `src/features/text-diff/views/TextDiffToolView.vue`：输入、渲染、同步滚动和差异导航；
- `src/features/text-diff/lib/textDiff.test.ts`：算法测试。

## 错误与性能

- Worker 计算失败时结束加载状态并展示错误信息；
- 新一次比较前终止上一个 Worker，避免旧结果覆盖新结果；
- 页面卸载时终止 Worker；
- 结果按结构化片段渲染并使用文本插值，避免 `v-html`；
- 长文本计算由 Worker 执行，结果面板固定尺寸并独立滚动。

## 测试与验收

算法测试覆盖：

- 完全相同文本；
- 新增行和删除行；
- 修改行及行内高亮；
- 空文本；
- 忽略空白开启和关闭；
- 连续差异块统计。

完成后运行：

- `npm test`；
- `npm run typecheck`；
- `npm run build`。

人工验收同步滚动、差异跳转不移动页面、移动端布局，以及长文本比较期间页面可响应。
