# SUMERU RING 内容路由与分页设计

## 背景

当前首页同时承担“全部内容”和“小工具列表”职责，两个侧栏菜单都指向 `/`，导致它们会同时显示选中状态。网址导航的展示与管理也集中在 `/links`，页面职责不够清晰，不利于后续继续增加工具、网址或其他内容类型。

本次调整将概览、分类列表和管理页面拆分为独立路由，并统一列表数量、分页和导航选中规则。

## 目标

- “全部内容”只展示各内容类型的摘要。
- “小工具”和“网址导航”拥有独立的完整列表页。
- 完整列表每页展示 16 项，超过 16 项时分页。
- 侧栏任何时刻只高亮一个内容入口。
- 网址展示与网址管理使用独立页面。
- 保持现有纯前端架构，网址继续存储在 IndexedDB。

## 路由设计

| 路径 | 页面职责 | 侧栏选中项 |
| --- | --- | --- |
| `/` | 全部内容概览 | 全部内容 |
| `/tools` | 全部小工具列表 | 小工具 |
| `/tools/jwt` | JWT 工具详情 | 小工具 |
| `/tools/qr-code` | 二维码工具详情 | 小工具 |
| `/tools/json` | JSON 工具详情 | 小工具 |
| `/tools/url-codec` | URL 编解码详情 | 小工具 |
| `/tools/character-count` | 字符统计详情 | 小工具 |
| `/links` | 全部网址导航 | 网址导航 |
| `/links/manage` | 网址管理 | 网址导航 |

未知路径继续重定向到 `/`。路由增加名称和内容类型元信息，侧栏根据当前路径所属内容类型计算激活项，不依赖 `RouterLink` 的模糊包含匹配。

## 页面设计

### 全部内容概览

首页按内容类型分区，首期包含“小工具”和“网址导航”。

- 每个类型最多展示前 5 项。
- 当该类型总数超过 5 项时，在第 6 个位置展示“查看更多”卡片。
- 当总数不足或等于 5 项时，不展示“查看更多”。
- 小工具“查看更多”跳转 `/tools`。
- 网址导航“查看更多”跳转 `/links`。
- 首页不提供标签或分类筛选，避免概览页与完整列表页职责重复。

### 小工具列表

- `/tools` 只展示注册表中 `type === 'tool'` 的内容。
- 保留标签筛选。
- 每页固定 16 项。
- 仅当筛选结果超过 16 项时显示 Element Plus 分页器。
- 标签变化后将页码重置为第 1 页。
- 当前页因数据变化超出有效页数时，自动回到最后一个有效页。

### 网址导航

- `/links` 展示 IndexedDB 中的全部网址。
- 页面标题使用“网址导航”，侧栏原“常用网址”同步改名。
- 保留网址分类筛选。
- 每页固定 16 项。
- 仅当筛选结果超过 16 项时显示 Element Plus 分页器。
- 分类变化后将页码重置为第 1 页。
- 页面右上角提供“管理网址”按钮，跳转 `/links/manage`。
- 外部网址仍在新标签页打开，并使用 `noopener noreferrer`。

### 网址管理

现有管理功能迁移到 `/links/manage`，新增、编辑、删除、排序、导入、导出和恢复默认行为保持不变。

## 组件边界

- `HomeView`：只组织各类型概览区块。
- `ToolListView`：负责工具筛选和分页。
- `LinkNavigationView`：负责网址分类筛选和分页。
- `LinkManagerView`：继续负责网址数据维护。
- 工具卡片和网址卡片抽取为共享展示组件，首页和完整列表页复用，避免样式与安全属性漂移。
- “查看更多”卡片作为独立通用组件或清晰的局部组件实现，只负责展示数量和路由跳转。

## 数据流

- 工具数据继续由 `contentRegistry` 提供。
- 网址数据继续通过 `initializeLinks()` 初始化，并通过 `listLinks()` 读取。
- 视图层先完成标签或分类筛选，再对结果执行分页切片。
- 当前页只保存在页面内存中，不写入 IndexedDB。
- 浏览器前进、后退由 Vue Router 管理；本次不要求将页码同步到 URL 查询参数。

## 异常处理

- IndexedDB 读取失败时，网址页面结束加载状态并展示 Element Plus 错误提示，不阻塞其他路由。
- 空列表显示明确的空状态，不展示无效分页器。
- 无效路径重定向到首页。

## 验收标准

1. 访问 `/` 时只有“全部内容”高亮。
2. 访问 `/tools` 或任意 `/tools/*` 时只有“小工具”高亮。
3. 访问 `/links` 或 `/links/manage` 时只有“网址导航”高亮。
4. 首页每种类型最多展示 5 条内容；总数大于 5 时额外展示一张“查看更多”卡片，否则不展示。
5. `/tools` 只展示工具，每页最多 16 项，筛选与分页行为正确。
6. `/links` 展示全部网址，每页最多 16 项，分类筛选与分页行为正确。
7. `/links` 右上角“管理网址”按钮可以进入 `/links/manage`。
8. 现有工具详情页、网址外链和网址管理功能均可正常使用。
9. 浏览器刷新、前进和后退不会出现错误选中态或错误页面。
10. 单元测试、类型检查和生产构建全部通过。
