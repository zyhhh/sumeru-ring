# SUMERU RING 网址导航设计

## 目标

在现有纯前端工作台中增加网址导航和网址管理能力。数据存储在当前浏览器的 IndexedDB，不引入后端。

## 分类与初始化数据

- 工具：JyShare、站长 DNS、JWT.io、草料二维码。
- 中转站：724AI、PU Coding。
- 资源：1MS、Foxirj。
- 影视：Pinglian。
- `macapp.org.cn` 不加入初始化数据。

初始化网址和用户新增网址采用相同规则，均允许编辑和删除。页面提供恢复默认网址功能。

## 数据模型

每条网址包含：ID、标题、URL、分类、标签、简介、排序值、是否为默认数据、创建时间和更新时间。

URL 仅允许 `http://` 和 `https://`。用户省略协议时自动补全 `https://`。

## 页面与交互

- 首页增加“常用网址”区域，按当前筛选条件展示网址卡片。
- 左侧“常用网址”进入独立管理页。
- 管理页支持搜索、分类筛选、新增、编辑、删除和排序。
- 外部网址统一在新标签页打开，并增加 `noopener noreferrer`。
- 删除和恢复默认数据使用确认弹窗。
- 支持 JSON 导出备份和导入恢复。

## 本地存储策略

- 首次访问时将初始化数据写入 IndexedDB。
- 恢复默认数据时恢复或覆盖默认网址，但保留用户自行添加的网址。
- 导入数据按 ID 更新或新增，不自动删除未出现在文件中的数据。
- 清理浏览器站点数据、切换浏览器或设备不会自动同步，需使用 JSON 备份迁移。

## 未来扩展

页面只依赖网址仓库接口，不直接调用 IndexedDB。未来增加后端同步时可替换仓库实现，不重写页面。
